三、 3 分钟极速上手：小火箭一键导入全自动配置教程

有了优质的节点订阅后，配置 Shadowrocket 只需简单的四步：

📌 步骤 1：准备海外 Apple ID 并安全下载 App

由于政策原因，国区 App Store 下架了小火箭软件。请打开 App Store，点击右上角个人头像滑动至最底部退出国区账号，登录美区或港区 Apple ID 搜索下载 Shadowrocket（认准正版蓝色火箭图标，切勿在 iPhone 系统设置中登录他人 iCloud）。

📌 步骤 2：获取并导入机场订阅链接

登录你所购买的高速机场后台（例如 快狸机场），在仪表盘找到 「一键订阅」 区域，点击复制小火箭订阅链接（或直接点击“一键导入到 Shadowrocket”）。

  1. 打开 Shadowrocket App，点击右上角 「+」 号；
  2. 在 「类型 (Type)」 处选择 Sub / Subscribe；
  3. 将复制的链接粘贴到 「URL」 框中，备注填写节点名称（如“快狸 IEPL 专线”），点击右上角 「完成」；
  4. 此时小火箭会自动刷新并完整列出所有高质量节点。

📌 步骤 3：选择智能分流模式 (Config)

小火箭首页提供三种全局路由模式，强烈推荐选择 「配置 (Config)」 模式：

  • 配置 (Config) 模式【强力推荐】： 最智能的分流方案。访问国内微信、淘宝、百度走本地直连，不消耗节点流量；访问海外 Google、YouTube、ChatGPT 自动代理加速。
  • 代理 (Proxy / Global) 模式： 所有网络流量强制走代理节点，适合测试节点或特定海外工作环境。
  • 直连 (Direct) 模式： 禁用任何代理转发，所有流量直连。

📌 步骤 4：节点连通性测试与一键开启

点击主界面第一行的 「连通性测试 (Test Connectivity)」，系统会自动向测试服务器发送 TCP 请求。挑选延迟最低（数值最小且显示绿色毫秒数）的优质节点，滑动最上方的 开关 允许建立 VPN 配置，即可畅享极速无感出海体验！

四、 小火箭高级功能进阶技巧（隐藏宝藏设置）

⚙️ 1. 自动延迟测试与智能节点排序

进入小火箭底部「设置」->「测试」，开启“自动测试”与“按延迟排序”。这样每次打开小火箭，系统都会自动将延迟最低、速度最快的专线节点排在最上方。

🛡️ 2. 防范 DNS 污染与 DoH (DNS-over-HTTPS) 加密

进入「设置」->「DNS 设置」，添加推荐的 DoH 加密 DNS 地址（如 https://doh.pub/dns-query），能有效规避本地运营商的 DNS 劫持与域名污染。

🔋 3. 电池省电与按需连接 (On-Demand) 优化

进入「设置」->「按需连接」，开启“自动按需建立连接”。当手机黑屏休眠或处于 Wi-Fi 环境时，系统会自动降低代理守护进程开销，显著提升 iPhone 电池续航。

五、 小火箭常见故障自查与排障指南 (FAQ)

Q1：节点测试显示绿色毫秒数，但打开浏览器提示“无网络连接”？

排障方案： 90% 的情况是因为 iPhone 系统时间与网络标准时间不同步。请进入 iOS「设置」->「通用」->「日期与时间」，确保开启“自动设置”。此外可进入小火箭「配置」页面恢复默认规则。

Q2：机场订阅更新失败，提示“Server Returned 404 / 500”？

排障方案： 可能是订阅 Token 变动或官网地址更换。请重新登录机场后台复制最新的订阅链接，或关闭本地 Wi-Fi 尝试切换 5G 流量更新。

Q3：开启小火箭后，微信收发图片缓慢或淘宝打不开？

排障方案： 检查主界面路由模式是否误选为了“代理 (Global)”。切换回“配置 (Config)”模式即可恢复国内流量本地直连。
